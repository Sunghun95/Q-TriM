## Abstract

> Audio-Visual Question Answering requires joint reasoning over video, audio, and text.
> Q-TriM introduces a shallow and parallel multimodal attention framework that captures question-guided interactions across the three modalities. Instead of deeply stacking sequential fusion modules, Q-TriM directly models complementary video-audio-text relations through question-conditioned attention operations, enabling efficient multimodal reasoning for AVQA.
